易位 eaSEAT

老师的排座位小助手

录入学生名单、画好教室布局，一键排好座位。可以按身高、完全随机或大组轮换，指定不坐在一起的同学，还能每周一早上自动重排。学生和家长加入班级后随时查看最新座位表。

功能

2.0 版本新增了大组轮换、不相邻名单和每周自动重排。

高

按身高排座

矮的同学坐前面；身高相近的同学每次随机交换位置，没填身高的同学随机安排。

轮

大组轮换

每个大组整体向右移一组，最右边的组移到最左边，同桌和前后排都不变。

隔

不相邻名单

指定两位同学，排座时他们既不做同桌，也不坐前后桌。

周

每周自动重排

打开后每周一早上 6:00 自动换座位，打开小程序就能看到。

换

点选交换

点一个座位、再点另一个，两人就换了位置；也可以直接修改座位上的姓名。

享

导出与分享

生成座位表图片发到家长群，或复制到 Excel / WPS；分享班级卡片，点开即可加入查看。

设置

座位表

先用“按身高”排一次，再切换到“大组轮换”点“排座”，就能看到每个大组整体右移。

排座是怎么算的

算法在 arrange.js，小程序和这个网页用的是同一份代码，并有自动化测试。

按身高

给每位同学的身高加上 ±3 厘米的随机扰动后从矮到高排序，从第一排开始依次坐满；同一排内左右位置随机。这样前后顺序基本按身高，但身高相近的同学每次会换位置。

大组轮换

整列都没有课桌的地方被当作过道，过道把教室分成几个大组。每一排里，每个大组的同学整体搬到右边一组；课桌数不同时，多出来的同学坐到同一排最近的空位。

不相邻名单

排好后检查每一对“不相邻”的同学是否同桌或前后桌。如果是，就把其中一人和别人交换——优先在同一排里换，尽量不打乱身高顺序。座位实在太挤时会提示还有几组没能分开。

数据与隐私

只保存排座需要的班级名称、学生姓名和身高。只有班级创建者能看到名单和身高，其他人只能看座位表；上传的 Excel 读取后立即删除。
